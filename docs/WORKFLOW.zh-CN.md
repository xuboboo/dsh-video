# dsh-video 工作流

Video Studio 如何映射到多模型 AI 视频制作流水线
（来源：《Claude Code/Codex + Seedance AI 视频：从一个想法到成片的全流程》）。

English version: [WORKFLOW.md](./WORKFLOW.md)

## 角色分工

| 角色 | 承担者 | 职责 |
| --- | --- | --- |
| 你 | 人 | 选方向、确认画风、批准花钱；看动态、听声音。 |
| 导演 | 编码智能体（Claude Code / Codex / Harness 会话） | 写故事和分镜，写所有提示词，调用其他模型，抽帧检查每张图和每段视频，用 ffmpeg/Python 做后期。 |
| 画师 | 图像模型（如 Codex 驱动的图像生成） | 设定图、样帧，以及每个镜头的首尾帧。 |
| 动画师 | 视频模型（如 Seedance） | 把首尾帧变成几秒钟的视频。按秒计费——尽量少重生成。 |

## 省钱原则

改提示词免费，重画一张图便宜，重生成视频按秒收费。
因此：**能在文字里发现的错，不要留到图上；能在图上发现的错，不要留到视频上。**

## dsh-video 在哪里发力

1. **规划** —— 新建项目；设置画幅、目标片长、预算。
2. **分镜** —— 每个镜头一行：画面、机位/运镜、首尾帧提示词、视频提示词。
3. **执导** —— 把复制的「总导演提示词」粘贴到新的 Harness 会话；智能体根据你的提示词驱动画师与动画师模型。
4. **推进** —— 每个镜头完成后点击状态徽章推进；页头显示 `完成/总数`。
5. **交付** —— 成片后把分镜导出为 Markdown 归档。

## 实用建议

- 镜头提示词要自成一体：主体、环境、光线、运镜、时长。
- 先用设定图锁定画风，再批量生成首尾帧。
- 整行镜头的首尾帧全部确认后，再批量生成视频。
